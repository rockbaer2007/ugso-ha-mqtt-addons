# Kombinationstest: GIF und Schneefall in Chrome

## Deutsch

**25. November 2026 · HA .197 · Card 0.1.12**

- Aktuelle Card-Ressource mit Versionsparameter 0.1.12 geladen.
- GIF aus dem eigenen lokalen Ordner erfolgreich geladen und sichtbar.
- 30 Schneeflocken, Ebene `effects force-snow`; Animation `snow-fall`, Zustand `running`.
- Zwei Beobachtungen bestätigten unterschiedliche Flockenpositionen.
- Bei diesem abschließenden Kombinationstest keine Einstellungen verändert.

Bei der vorherigen Diagnose lud Chrome noch die Ressource 0.1.8. Die gespeicherte
Ausnahme war im neuen Editor bereits aktiv. Nach Sicherung des bisherigen
Verweises wurde ausschließlich die eigene Card-Ressource aktualisiert und das
Dashboard neu geöffnet. Zeitpläne und Effekteinstellungen wurden dabei nicht geändert.
Der Nutzer aktivierte anschließend das Bild wieder; der abschließende Test war rein lesend.

Dieser Befund ersetzt den zuvor offenen Kombinationstest, ist aber kein
allgemeiner Geschwindigkeits-/Tablet-Test und keine Zusicherung für jede Browserkonfiguration.

## English

**November 25, 2026 · HA .197 · Card 0.1.12**

A loaded local GIF and 30 moving snowflakes were confirmed together in Chrome.
The effect layer was `effects force-snow`; animation `snow-fall`, state `running`.
Two observations showed different particle positions. No settings were changed
during this final combination test.

The earlier diagnosis found that Chrome still loaded resource 0.1.8 although the
override was saved in the current editor. The previous URL was backed up; only
the card resource was updated and the dashboard reopened. Schedules and effects
were untouched. The user then re-enabled the image before the read-only retest.
This confirms the combination on this installation, not performance on all tablets.

## Français

**25 novembre 2026 · HA .197 · Carte 0.1.12**

Un GIF local chargé et 30 flocons mobiles ont été confirmés ensemble dans Chrome.
Couche `effects force-snow`, animation `snow-fall`, état `running`. Les positions
ont changé entre deux observations. Aucun réglage n'a été modifié pendant ce test final.

Le diagnostic précédent avait trouvé l'ancienne ressource 0.1.8 malgré l'exception
enregistrée dans l'éditeur actuel. L'ancienne URL a été sauvegardée ; seule la
ressource de la carte a été actualisée, puis le tableau de bord rouvert. Horaires
et effets inchangés. L'utilisateur a ensuite réactivé l'image avant le test en
lecture seule. Cette confirmation ne garantit pas les performances de toutes les tablettes.
