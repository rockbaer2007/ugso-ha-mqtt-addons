Benutzer für alle Ansichten oder einzeln zuordnen.

Diese App steuert die Sichtbarkeit der Ansichts-Tabs. Direkte URLs bleiben erreichbar. Sie ersetzt keine Zugriffsrechte.

—Keine Änderungen

Abbrechen beendet das Warten. Ein bereits gesendeter Schreibauftrag kann weiterlaufen; anschließend Serverstand prüfen.

    Über „Neu laden“ erneut prüfen. Fehlgeschlagene Dashboards gelten nicht als leer.

    U = BenutzerA = AdministratorStrich in der Checkbox = teilweise ausgewählt

    Im Spaltenkopf alle Ansichten eines Benutzers auswählen oder abwählen. Die Checkboxen darunter ändern jeweils nur eine Ansicht.

    Ansichten als Zeilen, Benutzer als Checkbox-Spalten

    Haken = sichtbar. Änderungen werden erst beim Speichern übernommen. Bearbeitete Ansichten erhalten feste Benutzerlisten; neue Benutzer werden dort nicht automatisch ergänzt. Unteransichten behalten ihre Kennzeichnung. Karten und Layouts bleiben erhalten.

    Sicherungen

    Vor jedem Speichern

    Vollständige Dashboard-JSON im privaten App-Speicher. Wiederherstellen ist nur möglich, solange das Dashboard danach nicht anderweitig geändert wurde.

    Dashboard-Vorauswahl

    Nur angehakte Dashboards erscheinen in der Dropdownliste. Die Vorauswahl wird in diesem Browser gespeichert; Dashboards und Benutzerzuordnungen bleiben unverändert.
