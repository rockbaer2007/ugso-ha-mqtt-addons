Declarative block schemas adapted from ioBroker/ioBroker.javascript:
https://github.com/ioBroker/ioBroker.javascript
Revision a1dde1a3a5a7c14be2f99f34f523a01b75f79384 (10.5.0)
src/lib/fb/library.ts, inspected together with types.ts, graph.ts,
analyze.ts, generate.ts and docs/de/fbd.md.

The metadata extract web/reference-blocks.json retains pin names, types,
parameters and defaults; runtime code was removed. web/catalog.js adapts
HA inputs/outputs. No ioBroker editor, generated runtime or artwork included.
The graph model and restricted HA exporters are an independent prototype.

Since 0.1.8 the editor canvas uses React Flow (@xyflow/react, MIT), React and
React DOM (MIT). Dependencies are bundled locally in web/vendor; no CDN is used.
The complete production dependency license texts are included in
web/vendor/THIRD-PARTY-LICENSES.txt. The React Flow attribution remains visible.
Sources: https://reactflow.dev/ and https://github.com/xyflow/xyflow .
Build: npm ci, then npm run build (Node 22+). Running the packaged Python/HA
app does not require Node.js, npm, or access to the npm registry.

Runtime YAML parsing: PyYAML 6.0.3, MIT license, https://pyyaml.org/ .

The shared native Blockly catalog and HA YAML exporter come from UGSo Blocks
for HA 0.1.66, Apache-2.0, source revision d9c88d73d28b09110c9cdd64224cea0321d1f22d:
https://github.com/rockbaer2007/ugso-ha-mqtt-addons/tree/d9c88d73d28b09110c9cdd64224cea0321d1f22d/blocks_for_ha
The imported catalog lives under frontend/blocks-for-ha. Logic Studio Pro
adapts its language selection and editor integration. The license ships as
web/vendor/blocks-for-ha-LICENSE.txt.
Installed by pip during the HA container build; its license remains in the
installed package metadata. Jinja2 is a BSD-licensed development/test dependency
only, not required by the running app.
